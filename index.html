FLIP WARS

Design & Analysis of Algorithms — Team 13

A strategic tile-flipping board game with an AI engine powered by Alpha-Beta Minimax, Zobrist DP Hashing, Zero-Allocation Backtracking, and a Bottom-Up Bitmask Oracle. Built with Java 23 & JavaFX.

⬇ Download FlipWars.zip View Source on GitHub

🎮 3 Grid Sizes

Play on 4×4, 5×5, or 6×6 boards with dynamic AI depth scaling.

🧠 R3 AI Engine

4 interconnected algorithms: Backtracking, Alpha-Beta, Zobrist TT, and Bitmask Oracle.

🕳️ Black Holes

2 random un-clickable tiles per game create an irregular graph topology.

📊 Brain Scanner

Live dashboard showing nodes explored, prunes fired, and cache hits per turn.

R3 Engine — 4 Master Algorithms

# Algorithm Type Complexity Owner
1 Pure Backtracking In-place XOR O(1) per call SUHAS

3 Zobrist Transposition Table DP Memoization O(1) lookup GANESH
4 Bitmask DP Oracle (4×4) Bottom-Up BFS O(1) query BALAJI
